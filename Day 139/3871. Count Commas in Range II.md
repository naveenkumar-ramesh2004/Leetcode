## [3871. Count Commas in Range II](https://leetcode.com/problems/count-commas-in-range-ii/description/)
```
class Solution {
    public long countCommas(long n) {
        long result=0;
        for(int i=1;i<=5;i++){
            result+= Math.max(0,n-(Math.pow(1000,i)-1));
        }
        return result;
    }
}
