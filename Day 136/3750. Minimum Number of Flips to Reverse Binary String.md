## [3750. Minimum Number of Flips to Reverse Binary String](https://leetcode.com/problems/minimum-number-of-flips-to-reverse-binary-string/description/)

```
class Solution {
    public int minimumFlips(int n) {
        StringBuilder bit = new StringBuilder();
        while(n!=0){
            bit.append(n%2);
            n/=2;
        }
        int low=0,high=bit.length()-1;
        int flip=0;
        while(low<high){
            if(bit.charAt(low)!=bit.charAt(high)) flip+=2;
            low++;
            high--;
        }
        return flip;
    }
}
