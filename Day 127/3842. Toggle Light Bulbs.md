## [3842. Toggle Light Bulbs](https://leetcode.com/problems/toggle-light-bulbs/description/)

```
class Solution {
    public List<Integer> toggleLightBulbs(List<Integer> bulbs) {
        int[] bulbOnOff = new int[101];
        for(int bulb:bulbs){
            if(bulbOnOff[bulb]==0) bulbOnOff[bulb]=1;
            else bulbOnOff[bulb]=0;
        }
        List<Integer> result = new ArrayList<>();
        for(int i=0;i<101;i++){
            if(bulbOnOff[i]==1) result.add(i);
        }
        return result;
    }
}
