## [3718. Smallest Missing Multiple of K](https://leetcode.com/problems/smallest-missing-multiple-of-k/description/?envType=daily-question&envId=2026-08-27)
```
class Solution {
    public int missingMultiple(int[] nums, int k) {
        HashSet<Integer> set = new HashSet<>();
        for(int val:nums){
            set.add(val);
        }
        int i=1;
        while(set.contains(i*k)) i++;
        
        return i*k;
    }
}
