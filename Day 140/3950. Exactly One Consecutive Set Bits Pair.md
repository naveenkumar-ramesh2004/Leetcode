## [3950. Exactly One Consecutive Set Bits Pair](https://leetcode.com/problems/exactly-one-consecutive-set-bits-pair/description/)

```
class Solution {
    public boolean consecutiveSetBits(int n) {
        String bit = Integer.toBinaryString(n);
        int count=0;
        for(int i=0;i<bit.length()-1;i++){
            if(bit.charAt(i)=='1' && bit.charAt(i+1)=='1'){
                count++;
            }
        }
        return (count==1)?true:false;
    }
}
