## [455. Assign Cookies](https://leetcode.com/problems/assign-cookies/description/)

```
class Solution {
    public int findContentChildren(int[] g, int[] s) {
        if(g.length==0 || s.length==0) return 0;
        Arrays.sort(g);
        Arrays.sort(s);
        int i=0;
        int j=0;
        int result=0;
        while(i<g.length && j<s.length){
            if(g[i]<=s[j]){
                result++;
                i++;
            }
            j++;
        }
        return result;
    }
}
