## [2220. Minimum Bit Flips to Convert Number](https://leetcode.com/problems/minimum-bit-flips-to-convert-number/description/)

```
class Solution {
    public int minBitFlips(int start, int goal) {
        int xor=start^goal;
        int ans=0;
        while(xor!=0){
            xor=xor&(xor-1);
            ans++;
        }
        return ans;
    }
}
