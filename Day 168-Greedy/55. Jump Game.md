## [55. Jump Game](https://leetcode.com/problems/jump-game/)

```
class Solution {
    public boolean canJump(int[] nums) {
        int furthest=0;
        for(int i=0;i<nums.length;i++){
            furthest=Math.max(furthest,i+nums[i]); // remember how far we can go
            if(furthest-i>=nums.length-i-1) return true; // check we can reach the end return true
            if(furthest-i==0) return false;  // we can't move one step ahead of zero jump return false
        }
        return false;
    }
}
