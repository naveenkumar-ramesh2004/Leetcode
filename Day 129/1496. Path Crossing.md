## [1496. Path Crossing](https://leetcode.com/problems/path-crossing/description/)

```
class Solution {
    public boolean isPathCrossing(String path) {
        int x=0,y=0;
        HashSet<String> points = new HashSet<>();
        points.add("0,0");
        for(char direction:path.toCharArray()){
            if(direction=='N') x++;
            if(direction=='S') x--;
            if(direction=='E') y++;
            if(direction=='W') y--;
            String temp=x+","+y;
            if(points.contains(temp)) return true;
            points.add(temp);
        }
        return false;
    }
}
