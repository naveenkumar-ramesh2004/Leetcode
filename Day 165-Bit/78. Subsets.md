## [78. Subsets](https://leetcode.com/problems/subsets/description/)
```
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        int  possibleSubSet=(1<<nums.length); // 2^n;
        for(int i=0;i<possibleSubSet;i++){
            ArrayList<Integer> temp = new ArrayList<>();
            for(int j=0;j<nums.length;j++){
                if((i&(1<<j))!=0) temp.add(nums[j]);
            }
            ans.add(temp);
        }
        return ans;
    }
}

//Time: 1st for loop run 2^n and 2nd for loop n times so => 2^n*n;
//Space we never use any extra space O(1) the (temp, ans) is used for result if it also consider O(2^n);
