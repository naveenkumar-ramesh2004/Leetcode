## [260. Single Number III](https://leetcode.com/problems/single-number-iii/description/)
```

// LeetCode 260 — Single Number III

// Here the difference from Single Number II is:

// Every number appears twice
// Exactly two numbers appear once
// Find those two numbers.

// Example:

// nums = [1, 2, 1, 3, 2, 5]

// Answer:

// [3, 5]
// Key idea: XOR

// If:

// a ^ a = 0
// a ^ 0 = a

// So if we XOR everything:

// 1 ^ 2 ^ 1 ^ 3 ^ 2 ^ 5

// Pairs cancel:

// (1 ^ 1) ^ (2 ^ 2) ^ 3 ^ 5
// = 0 ^ 0 ^ 3 ^ 5
// = 3 ^ 5

// So we get:

// xor = 3 ^ 5

// But we still need to separate 3 and 5.

// Step 1: Find a different bit
// int xor = 0;

// for (int n : nums) {
//     xor ^= n;
// }

// Now:

// 3 = 011
// 5 = 101

// 3 ^ 5 = 110

// 110 tells us that bits 1 and 2 are different.

// We can take the rightmost different bit:

// int diffBit = xor & -xor;

// For xor = 110:

//  xor   = 110
// -xor   = 010

//   110
// & 010
// -----
//   010

// So:

// diffBit = 010
// Step 2: Divide numbers into two groups

// We use:

// if ((n & diffBit) != 0)

// Group 1 → bit is 1

// Group 2 → bit is 0

// Since 3 and 5 have different values at this bit, they go into different groups.

// Then XOR each group.

// Complete code
// class Solution {
//     public int[] singleNumber(int[] nums) {
//         int xor = 0;

//         for (int n : nums) {
//             xor ^= n;
//         }

//         int diffBit = xor & -xor;

//         int a = 0;
//         int b = 0;

//         for (int n : nums) {
//             if ((n & diffBit) != 0) {
//                 a ^= n;
//             } else {
//                 b ^= n;
//             }
//         }

//         return new int[]{a, b};
//     }
// }
// The main concept
// XOR everything
//       ↓
// get a ^ b
//       ↓
// find a bit where a and b differ
//       ↓
// divide numbers into 2 groups
//       ↓
// XOR each group
//       ↓
// get a and b

// Time: O(n)
// Space: O(1) apart from the output array.

```
---
```

class Solution {
    public int[] singleNumber(int[] nums) {
        int xor=0;
        for(int n:nums){
            xor^=n;
        }
        int rightmostbit=(xor^xor-1)&xor;
        int b1=0,b2=0;
        for(int n:nums){
            if((n & rightmostbit)!=0){
                b1^=n;
            }
            else{
                b2^=n;
            }
        }
        return new int[]{b1,b2};
    }
}
