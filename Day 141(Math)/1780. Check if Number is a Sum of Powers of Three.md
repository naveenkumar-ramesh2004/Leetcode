## [1780. Check if Number is a Sum of Powers of Three](https://leetcode.com/problems/check-if-number-is-a-sum-of-powers-of-three/description/)

```
class Solution {
    public boolean checkPowersOfThree(int n) {
        while(n!=0){
            if(n%3>1) return false;
            n/=3;
        }
        return true;
    }
}
